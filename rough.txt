App to Add, delete, view and update contacts in device.

Tech Stack:
-Node.js for runtime
-Express for lightweight web-server
-Prisma for ORM
-Postgresql for db

index.js
/models
/views
/controllers


/routes
1. GET /contacts : list all contacts
2. GET /contacts/:id get one contact
3. POST /contacts create a contact
4. PUT /contacts/:id update one contact
5. DELETE /contacts/:id Delete a contact


server is a computer running on a port looking 
for http requests!
server can be written in many languages,
javascript ,requires node.js as a runtime env to compile 
express is  a framework/library for making efficient servers
